Описание архитектуры и порядок добавления новых алгоритмов анонимизации
Архитектура:  
    - Базовый класс BaseAnonymizer (файл base.py) задаёт единый интерфейс для всех стратегий анонимизации. Он содержит:  
        - Абстрактный метод _generate(value, row), который реализует конкретное преобразование.
        - Метод anonymize(value, row), обеспечивающий детерминизм через глобальный кэш (одинаковые исходные значения заменяются одинаково).
        - Реестр StrategyRegistry (registry.py) хранит соответствие строковых имён (например, "rus_name") и классов-стратегий.
        - Пайплайн AnonymizationPipeline (pipeline.py) загружает конфигурацию YAML, находит нужную стратегию через реестр, создаёт её экземпляр с параметрами и применяет ко всем строкам таблицы.
        - Все стратегии лежат в папке anonymizer/strategies/ и наследуются от BaseAnonymizer.

Порядок добавления нового алгоритма:
    1. Создать файл anonymizer/strategies/my_new_strategy.py.
    2. Написать класс, унаследованный от BaseAnonymizer:
        python

        from anonymizer.strategies.base import BaseAnonymizer

        class MyNewStrategy(BaseAnonymizer):
            def _generate(self, value, row=None):
                # реализация анонимизации
                return transformed_value
    При необходимости можно использовать self.params – параметры из конфига.
    Зарегистрировать класс в файле anonymizer/strategies/__init__.py:
    python. Пример:

        from .my_new_strategy import MyNewStrategy
        StrategyRegistry.register('my_algorithm_name', MyNewStrategy)

    Использовать в конфигурации (anonymization.yaml):
    yaml

    tables:
        some_table:
            columns:
                some_column:
                    algorithm: my_algorithm_name
                    params:
                        param1: value1

Изменять основной код (пайплайн, загрузчик конфига, работу с БД) не требуется – архитектура расширяема.
